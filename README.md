成都中启易联科技有限公司（简称「中启易联」）专注于 AI 训练数据服务，提供**采购 + 自制双轨、合规版权**的成品数据集，覆盖大模型训练全生命周期——从预训练语料到推理增强、从多语种语音到具身与世界模型。

## 重点数据方向

- **中英文期刊 / 硕博论文** — 多学科中英文文献、期刊论文、硕博学位论文、CSSCI、专利等，文本模态，量级千万至亿级。
- **竞赛题** — 中英文初高中 / 大学数学竞赛题、中高考试题、推理型题库，支持深度推理与逻辑能力训练。
- **医疗数据** — 医疗论文期刊、医疗问答、中英医疗平行句对、医疗题库、医疗 CT 影像、医疗报告、医学视频，跨模态合规交付（去标识化）。
- **多模态通用数据** — 图文、语音（含方言 / 多语种 ASR·TTS）、视频、具身与世界模型数据、一带一路东盟语料、阿拉伯语专项语料等。
